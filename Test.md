## Kapitel 2: Neue Fähigkeiten

Dieses Jahr habe ich auch programmieren gelernt. Um in Python "Hallo Welt" auszugeben, schreibt man den Befehl `print("Hallo Welt")` als Inline-Code. Hier ist derselbe Code auch als vollständiger, formatierter Codeblock in der Sprache Python:
```python
print("Hallo Welt")
```
